## Overview

This is Izzy Piyale-Sheard's original personal brand and portfolio website. The site opens with a bold "Hello, World! I'm Izzy" introduction over a fullscreen background, with rotating taglines (Career Coaching, Websites, Automation). It features an about section with personal bio, a services carousel (Websites, Career Coaching, Growth Hacking), a visual timeline resume highlighting roles at Hacker Paradise, NomadKit, Clear Career, Snapsy Photobooth, freelance web development, and the University of Toronto. The "Remote As Fuck" photo gallery showcases working-from-anywhere shots across Indonesia, Vietnam, Japan, Spain, and Thailand. Social links connect to Twitter, Instagram, YouTube, LinkedIn, and Medium.

## Features

- Fullscreen hero section with animated intro text and social media sidebar

## Getting Started

### Run Locally

No build step required:

1. **Clone the repository**
   ```bash
   git clone https://github.com/izzydoesizzy/izzydoesizzy.git
   cd izzydoesizzy
   ```

2. **Open in browser**
   ```bash
   open index.html
   # or use a local server:
   npx serve .
   ```

### Deploy to GitHub Pages

1. Push to the `gh-pages` branch
2. Go to Settings > Pages > Source: Deploy from branch
3. Site live at `https://izzydoesizzy.github.io/izzydoesizzy`
